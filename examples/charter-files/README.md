# Example program charters (illustrative)

Real filled `charter.md`s from NV-magnetometry / ASI campaigns, kept as **voice/altitude references**
for `new-campaign` and as concrete instances of archetypes **A** (`charter_residual.md`), **B**
(`charter_forward.md`), **D** (`charter.md`), **E** (`charter_hardware_loop.md`), and **F** (`charter_ASI_CNN.md`).

> **Caveat — these predate the current methodology.** They were written before the v0.3 additions (the
> `frame-problem` / verification-plan / project-orientation docs, the archetype set A–I, the git
> downgrade, etc.), and they're all from one subfield. Treat them as illustrations of **structure and tone**,
> not as current best-practice templates. Worth refreshing — and adding a non-NV example — when convenient.

> **Exception:** `charter_hardware_loop.md` (archetype E) postdates v0.3: it is written against the current
> methodology, distilled from a qualified autonomous loop on a low-field, microscale NV-diamond-detected NMR spectrometer, and pairs with
> `docs/reference/hardware-in-the-loop.md`.
