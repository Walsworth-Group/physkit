# Example program charters (illustrative)

Real filled `program.md` charters from NV-magnetometry / ASI campaigns, kept as **voice/altitude references**
for `new-campaign` and as concrete instances of archetypes **A** (`program_residual.md`), **B**
(`program_forward.md`), **D** (`program.md`), and **F** (`program_ASI_CNN.md`).

> **Caveat — these predate the current methodology.** They were written before the v0.3 additions (the
> `frame-problem` / verification-plan / project-orientation docs, the archetype set A–I, the git
> downgrade, etc.), and they're all from one subfield. Treat them as illustrations of **structure and tone**,
> not as current best-practice templates. Worth refreshing — and adding a non-NV example — when convenient.
